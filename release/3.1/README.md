# Grep 3.1

Clone clean-room do dBASE II para MSX2/MSX-DOS 2.

## Arquivo

- `msxdbase-3.1.com`: executavel MSX-DOS 2.

Copie o `.COM` para um disco MSX-DOS 2 e execute no prompt. `HELP` mostra o resumo local. Os topicos detalhados exigem uma copia licenciada externa de `DB8SEMSG.TXT`; esse arquivo nao acompanha o release.

Leia [RELEASE.md](RELEASE.md) para destaques e limitacoes. Mutacoes suportadas sao destinadas a DBF II (`0x02`); mantenha backups.
