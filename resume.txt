MSX dBASE III- / dBASE II+  -  RESUMO DO PROJETO E DO DIA
Ultima atualizacao: 2026-10-29

=== O PROJETO ===
Ambiente xBase nativo para MSX2/2+/turbo R: nucleo compativel com dBASE II, recursos
selecionados do dBASE III. C + SDCC + MSXgl, MSX-DOS 2, Memory Mapper.
Projeto de estudo: codigo modular e muito comentado.
Documentos: SPEC.md (especificacao viva), OUTLINE.md (progresso por fase/sub-fase),
este resume.txt (retomada rapida em outro PC/IA). DBASE_MSX_DIRETRIZES.md foi
incorporado ao SPEC (secao 6) e fica so como historico.

=== COMO RETOMAR (outro PC / outra IA) ===
1. Ler este arquivo, depois OUTLINE.md e SPEC.md (secoes 6, 7 e 8).
2. Compilar: .\build.ps1 (na raiz). FECHAR o openMSX antes, senao a copia do .dsk falha.
3. Executar: openmsx -machine Boosted_MSX2_EN -ext msxdos2 -diska .\project\emul\dsk\DOS2_msxdbase.dsk
4. Gerar o DBF de teste (se faltar): pwsh project\data\make_sample_dbf.ps1
5. Teste basico no prompt: ver / use clientes / list / display structure / go 3 / display / skip -1 / go bottom / quit

=== VERSIONAMENTO ===
- X representa marco funcional e usa codinome de conceito Unix/C classico, sem nomes de pessoas.
- Y incrementa a cada build bem-sucedido; pode ser mantido durante testes com -KeepVersion.
- Tag: X.Y; titulo do release: <codinome>: descricao curta.
- RELEASE.md guarda notas completas; Changelog.MD resume cada versao.

=== DECISOES / PONTOS EM ABERTO ===
- Variante dBASE III 0x03 mantida apenas como fixture de leitura/interoperabilidade; DBF II MSX e o formato-alvo. Padding/EOF da amostra original ainda nao foram determinados.
- Limites atuais: 32 campos, registro de ate 256 bytes.
- Em aberto: Numeric em BCD ou decimal fixo; nome definitivo do projeto.
- Ordem decidida: completar compatibilidade dBASE II MSX, depois extensoes dBASE III e UI avancada.
- DECIDIDO: minimo absoluto 512 KB de Memory Mapper; alvo real 1024 KB (nao projetar para 128/256 KB).
- DECIDIDO: video e teclado NUNCA pelo console do MSX-DOS/CP/M: VDP direto e BIOS.

=== LICOES TECNICAS (detalhes no SPEC secao 7) ===
- Sob MSX-DOS a ROM principal NAO esta mapeada: nao ler variaveis/fonte da BIOS.
- msxgl_config.h precisa de PRINT_USE_TEXT, PRINT_WIDTH_1, PRINT_HEIGHT_1.
- Teclado: DIRIN do MSX-DOS (07h); desligar cursor da BIOS (0xFCA9) e restaurar ao sair.
